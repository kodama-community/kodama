# Version 1.1.1 release

Commit range: `92e2395..1829657`

## Highlights
- Fixed a regression introduced in 1.0.0: backslashes in subtree tag attribute values (e.g. `title="$\sqrt{\Delta} \in F$"`) were being stripped during parsing, corrupting LaTeX math in titles and taxons.

## Stability and error handling
- Subtree attribute values are now scanned in a single pass that unescapes only `\"` and `\\`, preserving all other backslashes (LaTeX commands) and multi-byte characters.
- Added test coverage for LaTeX titles, escaped quotes, and multi-byte characters in attribute values.

## Full commit list
- `1829657` fix: preserve backslashes in subtree tag attribute values
