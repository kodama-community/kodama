# Version 1.1.2 release

Commit range: `1829657..e6a1891`

## Highlights
- **Typst 0.15 compatibility**: this release adapts Kodama's Typst integration to the Typst 0.15 HTML export and fixes the regressions that appeared after upgrading.
- Inline math baseline alignment (`vertical-align`) is restored, inline Typst SVGs render inline again (no forced `display: block`), and the theme's `#000000` color replacement works again for inline Typst SVGs.

## What changed in Typst 0.15 and how this release fixes it
- `here().position().y` now returns `0pt` during HTML export, which broke the previous two-pass `state`-based mechanism that computed inline math's vertical offset. This release replaces it with a direct `measure`-based baseline computation, so inline equations get their `vertical-align` back (matching pre-0.15 values).
- `html.frame` output is now treated as block-level by Typst 0.15 (the exported `<svg>` carries `display: block`), and the SVGs no longer carry the internal `typst-text` / `typst-group` / `typst-shape` classes that the theme's color replacement previously relied on. This release:
  - wraps Typst frames in `box()` so SVGs render inline again (both inline math and `auto-frame` output);
  - rescopes the `#000000` fill/stroke theme replacement to Kodama's own wrapper classes (`.typst-inline`, `.typst-block`, `.inline-typst`, `.auto-frame`);
  - centers block equations via `.typst-block svg { margin-inline: auto; }`.

> **Note**: if you use Typst 0.15, upgrade to this latest version of Kodama — older releases render inline math without baseline alignment and may leave inline Typst SVGs black in dark mode.

## Stability and error handling
- Dropped the fragile `state`-based two-pass measurement (which could also fail to converge under Typst 0.15) in favor of a single-pass `measure`-based computation.
- Reverted the `color-invert` (SPSA filter) extension for inline math back to CSS-based theming; external figure images keep the existing `color-invert` filter.

## Refactors
- `snip katex` / inline sections no longer require configuration.
- Modeled built-in metadata as a typed struct.
