# Version 1.2.0 release

Commit range: `43b6d49..dde0f7c`

## Highlights
- **Built-in HTTP server for `kodama serve`**: local preview no longer depends on miniserve or any external static server. The built-in server binds `127.0.0.1` and reproduces the previous `--index index.html --pretty-urls` behavior.
- **Configurable preview port**: `[serve].port` pins the built-in server's port. Left unset, it uses the first free port from 8080; `0` lets the operating system choose one.
- **Faster incremental rebuilds**: compiled pages and Typst dependency caches are reused across watch batches, and unchanged HTML files are no longer rewritten.
- **More robust Typst rendering**: rendering errors now fail the build instead of being silently skipped, caches are invalidated when the Typst compiler or its inputs change, and Typst HTML output is handled more faithfully.

## Serve mode
- `kodama serve` starts a dependency-free HTTP/1.1 static server when `[serve].command` is empty. It serves `index.html` for directory requests, falls back to `<path>.html` for extensionless paths, handles percent-encoded paths, and rejects path traversal.
- The built-in server serves `GET` and `HEAD` requests only and sends `Connection: close` per request; it does not provide directory listings or keep-alive.
- Added `[serve].port` for the built-in server. An explicit port that is already in use reports an error instead of silently moving to another port. Setting `port` together with an external `command` is rejected.
- The accept loop now blocks on incoming connections instead of polling, so idle previews do not wake up periodically.
- Preview readiness is emitted after watch registration, so editors and tooling see the `ready` event only once the watch is active.
- External server commands remain supported through `[serve].command`, with `<output>` replaced by the serve output directory.

## Performance
- Serve-mode incremental builds reuse previously compiled pages from an in-memory cache instead of recompiling unchanged sources.
- Writer skips writing HTML files whose contents did not change.
- Typst dependency caches are shared between compiler runs, avoiding repeated cache copies and rebuilds.

## Typst
- Builds now fail on Typst rendering errors rather than continuing with missing output.
- Typst caches are invalidated when the Typst compiler or the inputs affecting it change.
- Typst marker attributes are parsed as HTML, preserving structured attribute values.
- Inline Typst bodies are extracted independently of paragraph markup, and styles from Typst HTML exports are hoisted into page heads.
- Markdown Typst figure URLs are resolved at compile time instead of being rewritten later.
- Removed unnecessary Typst version gating.
- Fixed horizontal scrolling for auto-frame figures by targeting Kodama's `.auto-frame` class.

## Markdown
- Link texts, image alt text, and Typst figure captions now accept the full set of inline syntax, including soft breaks, hard breaks, and formatting tags.
- Formatting stays scoped inside the link via nesting counts, and figure captions are HTML-escaped before insertion.

## Fixes and improvements
- Fixed the SPSA filter solver collapsing distinct colors to gray.
- Added a hint when the configuration file or the bundled Typst library is outdated.

## Internal
- Vendored `pulldown-cmark`, allowing the parser to be adjusted locally without patching a registry dependency.
- Replaced `include_str!` uses with a static `KODAMA_TYP` reference.
- Updated Rust dependencies.
- Bumped the KaTeX CDN to 0.18.5.

## Behavior changes and migration notes
- An empty `[serve].command` used to be invalid; it now selects the built-in server. Sites that previously configured `command = []` should either remove the field or provide an external command.
- The built-in server listens on `127.0.0.1` only. Use `[serve].command` with an external server if you need LAN access, directory listings, or other features.
- Typst rendering errors are now hard build failures. Existing sites with broken Typst input will stop building until the source is fixed.
- `--print-json` still requires `--no-server`.
