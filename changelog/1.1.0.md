# Version 1.1.0 release

Commit range: `8d740fd..42add7d`

## Highlights
- Added a `[suffix]` configuration table letting you choose the file suffixes for each source role. You can now adopt the standard `.typ` extension for typst content documents, use a custom markdown suffix, and set an explicit typst library/resource suffix.
- Batched inline typst compilation into a single compiler process, replacing per-formula process spawns.
- Reworked incremental change detection to use file `mtime + size` snapshots and cached hot-path environment values, shrinking rebuild work and process overhead.

## Behavior changes and migration notes
- The default suffixes are unchanged (`md`, `typst`, `typ`), so existing sites require no migration.
- `kodama new post --format` now accepts the stable identifiers `typ`/`md`; the created file gets the configured `[suffix]` extension for that format (defaults to `typ`).
- The `[suffix]` values must be pairwise distinct; `markdown`/`typst` must not be empty. Invalid values are rejected at config parse time.
- Internal naming cleanup: `Ext` renamed to `SectionKind`, and source files are now classified into an explicit `SourceRole` (markdown section / typst section / typst library / unknown) instead of the implicit "not a section" fallback.

## Features and improvements
- Added `[suffix]` config: `markdown`, `typst`, `typst-lib` suffixes for content and library documents. Library files under non-ignored directories are compiled to SVG rather than rendered as pages.
- `kodama new post --format` accepts `typ`/`md` and creates the file with the configured `[suffix]` extension.
- Inline typst (`$...$`) formulas are compiled in a single batched process invocation.

## Performance
- Cached hot-path derived environment values (paths, URLs, output flags) in an `Arc` snapshot instead of re-deriving per call.
- Replaced content-hash based change detection with `mtime + size` snapshots in the entry cache, avoiding hash work and writes when files are unchanged.
- Dropped output-content hash dedup in the writer; pages are always written.
- Memoized footer reference/backlink rendering per compile state.

## Stability and error handling
- Replaced the `itertools` dependency with a hand-written HTML tag stripper.
- Applied clippy nits (derive `Default`, minimal bools) and simplified match/ownership code.
- Bumped `pulldown-cmark` to 0.13.
